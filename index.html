2 · Definição

O que é uma estrutura de repetição?

03

É um comando que permite executar um bloco de instruções várias vezes, conforme uma condição.

Sem repetição

console.log(1);
console.log(2);
console.log(3);

Com repetição

for (let i = 1; i <= 3; i++) {
  console.log(i);
}
A condição deve permitir que a repetição termine.

6 · Exemplos

Contar para frente e para trás

07

De 1 até 10

for (let i = 1; i <= 10; i++) {
  console.log(i);
}

De 10 até 1

for (let i = 10; i >= 1; i--) {
  console.log(i);
}
i++ aumenta 1. i-- diminui 1. i += 2 aumenta 2.

function mostrar() {
  let n = Number(document.getElementById("numero").value);

9 · Integração

Repetição com decisão

10

Em cada volta do for, o if verifica uma condição.

let texto = "";
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) {
    texto += i + " é par<br>";
  } else {
    texto += i + " é ímpar<br>";
  }
}
document.getElementById("saida").innerHTML = texto;
O operador % calcula o resto da divisão.
10 · Acumulador

Somando os números de 1 a 5

11

Código

let soma = 0;
for (let i = 1; i <= 5; i++) {
  soma += i;
}
console.log(soma); // 15

Passo a passo

Depois de cada volta, a soma vale:

1 → 3 → 6 → 10 → 15

Um acumulador guarda o resultado parcial.

11 · while

Repetir enquanto a condição for verdadeira

12

Pseudolinguagem

i ← 1
ENQUANTO i <= 5 FAÇA
    ESCREVA(i)
    i ← i + 1
FIMENQUANTO

JavaScript

let i = 1;
while (i <= 5) {
  console.log(i);
  i++;
}
Não esqueça de atualizar i dentro do while.
12 · Comparação

for, while e do...while

13
EstruturaQuando usar
forQuando a contagem tem início, condição e atualização claros.
whileQuando queremos repetir enquanto uma condição for verdadeira.
do...whileQuando o bloco precisa executar pelo menos uma vez.
13 · Complemento

do...while testa no final

14
let i = 1;
do {
  console.log(i);
  i++;
} while (i <= 5);
O while verifica antes. O do...while executa antes e verifica depois.

Na prática inicial, nosso foco principal será o for.

17 · DOM + for

Alterando vários elementos

18

HTML

<p class="item">HTML</p>
<p class="item">CSS</p>
<p class="item">JS</p>
<button onclick="destacar()">Destacar</button>

JavaScript

function destacar() {
  let itens = document.querySelectorAll(".item");
  for (let i = 0; i < itens.length; i++) {
    itens[i].style.color = "blue";
  }
}
A primeira posição é 0. itens[i] acessa o elemento da posição atual.
18 · Eventos

De onclick para addEventListener

19

Antes

<button onclick="mostrar()">Mostrar</button>

Agora

<button id="botao">Mostrar</button>

// script.js
function mostrar() {
  alert("Olá!");
}
document.getElementById("botao")
  .addEventListener("click", mostrar);
O clique e a função são os mesmos. Agora a associação é feita no JavaScript.

mostrar

Coloque o script no final do body ou use defer.

22 · Atividade

Orientações para os exercícios

23

Construa interfaces HTML simples com campos, botões e elementos de resultado. Utilize funções, estruturas de repetição e DOM. Comece com getElementById e onclick; nas últimas questões, use os novos seletores e eventos.

Não use arrays, objetos, createElement nem bibliotecas externas.

Questões 1 a 4

24

1. Sequência numérica

Leia N e apresente de 1 até N em um parágrafo. Use for, função, onclick e getElementById.

2. Tabuada

Leia um número e mostre a tabuada de 1 a 10, uma operação por linha.

3. Números pares

Leia N e mostre os números pares de 1 até N. Use for e if.

4. Contagem regressiva

Leia um número e conte dele até zero usando for.

9. Destacar parágrafos
